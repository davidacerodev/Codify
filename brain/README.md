# Brain del proyecto

Este directorio conserva el contexto que necesita cualquier persona o agente para continuar Codify sin reconstruir decisiones desde cero. Leer los documentos en este orden:

1. `INSTRUCCIONES.md`
2. `CONTEXTO.md`
3. `ARQUITECTURA_Y_FLUJOS.md`
4. `DECISIONES.md`
5. La bitácora más reciente en `BITACORA/`
6. `SIGUIENTE_PASO.md` y el plan de trabajo que el usuario conserva fuera de este repositorio.

Antes de modificar código, revisar `git status`, las instrucciones locales y el avance. Al terminar, registrar archivos tocados, decisiones, verificaciones ejecutadas, resultado, riesgos y siguiente paso. No incluir secretos, datos reales de pacientes ni credenciales en estos documentos.

El usuario retiró `PLAN_TRABAJO/` y `docs/` de este checkout y conserva esos documentos fuera del proyecto. No recrearlos ni agregarlos a Git sin una solicitud explícita. Los registros de bitácora que mencionan esas rutas son antecedentes históricos.
